# Suggested Commands

- Shell environment: Windows `cmd.exe` semantics should be assumed for Serena shell commands unless explicitly configured otherwise.
- Repository currently has no project-specific build, test, lint, or format commands.
- `dir /a` and `dir /a /s /b` are available for Windows filesystem inspection.
- Git is not currently initialized in the project root, so Git commands should not be assumed to work until a repository is initialized.
