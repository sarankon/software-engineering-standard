Security Standard v1.0.0 drafted and implemented under `standards/security/`. Canonical files: `README.md` and `security-baseline.md`. It establishes 14 stable rules `SES-SEC-001` through `SES-SEC-014` covering security by design, authentication, authorization, secrets, sensitive-data exposure, input validation, output encoding, transport security, session security, dependency security, security event logging, error disclosure, least privilege, and security verification. It preserves the original five normative levels and rule structure, is technology-neutral, uses record_state/lifecycle_state governance, and keeps user approval as the authorization boundary. Lifecycle is currently `draft`; rules are not yet active. Existing standards are preserved. Next step should be review/validation and then additional standards using the same model.
