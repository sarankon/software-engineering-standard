# Software Engineering Standard

Versioned engineering standards for consistent software development across projects, including AI-assisted development.

## Structure

- `standards/` — engineering rules and practices.
- `ai_development/` — protocols for AI-assisted development.
- `blueprints/` — project-context structures.
- `migrations/` — upgrade paths between Standard and Blueprint versions.

## Principles

1. The Standard is the global source of truth for reusable engineering rules.
2. Project-specific knowledge belongs in the project's `project_context/`.
3. Standard and Blueprint versions are independent.
4. Updates use explicit migration and verification rather than blind copying.
5. Rules should be precise enough for both humans and AI agents to verify.

## Status

Foundation repository. Detailed standards will be developed incrementally and validated against real projects.
