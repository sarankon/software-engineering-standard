# Bootstrap Procedures

Bootstrap procedures define framework-level initialization workflows for target projects.

AI is the execution engine for bootstrap operations and performs the procedures directly in the target project. No separate Automated Bootstrap Runner or Framework Runtime Runner is required.

- `installation-procedure.md` - New Project Bootstrap Installation Procedure v1.0.0

Existing repositories use the Project Context Onboarding Procedure under `blueprints/project_context/ONBOARDING.md`.

- `installation-scenario-validation.md` - Installation Scenario Validation Procedure v1.0.0
