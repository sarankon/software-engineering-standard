# AI Handoff Domain

Provides a compact entry point for a new or returning AI agent.

Recommended information:
- current understanding
- current focus
- important context that must not be missed
- active constraints
- recommended next actions
- unresolved questions requiring user decisions

AI Handoff is a derived operational summary. It MUST NOT become the only source of truth; authoritative information remains in the relevant domains.

AI SHOULD refresh this domain when the project's active focus or important context changes.
