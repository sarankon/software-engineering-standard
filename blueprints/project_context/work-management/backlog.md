# Backlog

```yaml

title: <backlog item>
record_state: confirmed
work_state: backlog
source: user_decision | repository_analysis | ai_inference | external_reference
content: |
  <work description and useful context>
related_to:

```

Backlog ordering is advisory unless a priority field is explicitly added by the project.
