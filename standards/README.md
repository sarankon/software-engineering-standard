# Software Standards

The standards in this directory define reusable engineering rules for software projects.

## Organization

- `principles/` — foundational engineering principles.
- `architecture/` — architecture and boundary rules.
- `data/` — database, identity, audit, logging, and configuration data rules.
- `development/` — implementation and error-handling practices.
- `foundation/` — repository, project structure, dependencies, environment, and documentation rules.
- `integration/` — integration-related standards.
- `maintenance/` — maintenance and lifecycle standards.
- `operations/` — operational standards.
- `presentation/` — UI, interaction, and accessibility standards.
- `quality/` — quality and validation standards.
- `security/` — security standards.

Supporting files:

- `SPECIFICATION.md` — normative standard specification.
- `rule-template.md` — template for defining standard rules.
- `standard-relationships.md` — relationships among standards.
- `versioning.md` — standard versioning policy.
- `glossary.md` — shared terminology.
