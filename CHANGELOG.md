# Changelog

## 1.2.0 — Project Context Completion Gate

- Strengthened normal development completion with a mandatory Context Reconciliation Result.
- Required explicit classification of Project Context impact as `REQUIRED` or `NOT_REQUIRED`.
- Required affected domains, work state, updated Context files, AI Handoff status, and evidence-based reason before completion.
- Kept Project Context Blueprint and Schema versions unchanged because their data structures were not modified.

## 1.0.0 — Foundation

- Initialized Software Engineering Standard repository.
- Established top-level areas for standards, AI development, project-context blueprints, and migrations.
